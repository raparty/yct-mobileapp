## ✨ Features
- 📰 Magazine Library — Complete archive of *Yoga Chaitanya Prabha*
- 🎵 Audio Discourses — Stream Gurudev's teachings with in-app player
- 📚 Books & Publications — Telugu, English and bilingual books
- 📍 Centers Directory — All 15 centers with tap-to-call and Maps
- 💬 Daily Teaching — Fresh teaching from Gurudev each day
- 👤 About Gurudev — Life and teachings of Yogacharya Sri Raparthi Rama Rao

## 🏗️ Repository Structure
```
/                    → Flutter app (Android + iOS)
cloudflare/
  worker/            → yct-upload Cloudflare Worker (file upload API)
  admin/             → Admin panel (content management UI)
firestore/           → Firestore security rules + indexes
.github/workflows/   → CI/CD — builds APK/AAB + deploys to Cloudflare
```
